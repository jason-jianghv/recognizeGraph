# 识图设计系统

面向学龄前～小学低年级的拍照识物学习 App。所有 UI / Figma 产出必须遵循本规范，并与现有「探索 / 空间」稿视觉一致。

## 何时读取

| 场景 | 读什么 |
|------|--------|
| 画新页面 / 改样式 / 查色值字号 | 先读本文件，细节查 [tokens.md](tokens.md) |
| 对照页面结构与 PRD | [screens.md](screens.md) |
| 修订规范本身 | 改 [tokens.md](tokens.md)，并在文末「变更记录」追加一行 |

## 风格原则（儿童向）

1. **温暖明亮**：以珊瑚橙为主色，背景偏米白/浅桃，忌大面积冷灰或深色模式。
2. **大而清晰**：标题醒目、正文 ≥16、触控热区偏大，方便小手指。
3. **圆润友好**：大圆角、胶囊按钮；避免尖锐直角与密排信息。
4. **少字多图**：文案短、口语化、鼓励式；用插画/照片承载内容。
5. **主操作突出**：底部右侧拍照按钮始终可识别，勿淹没在 Tab 里。
6. **安全适龄**：不出现恐吓、低俗、过度游戏化诱导付费的视觉。

| 用途 | 值 |

| 页面背景 | `#FFF8F3` |

| 标题/主文字 | `#1A1A1A` |

| 成功/植物辅色 | `#2DB87A` |

## 工作流程（Figma / 实现）

1. **先对齐现稿**：已有「主题（探索）」「空间」两屏是视觉真源；新屏复用 Tab、主色、标题样式。
2. **再查令牌**：颜色/字号/圆角以 [tokens.md](tokens.md) 为准，勿临时发明第三套橙。
3. **按屏清单搭建**：结构对照 [screens.md](screens.md) 与根目录 `PRD.md`。
4. **儿童可读性自检**
   - [ ] 主按钮够大、对比够强
   - [ ] 正文可朗读长度适中；详情页有语音播报入口
   - [ ] 分类（动物/植物/交通建筑）有可区分的轻辅色，但不花哨抢主色
5. **改规范时**：只改 tokens，并写变更记录；同步提醒是否要回改已有 Frame。

## 文案语气

- 用「我们一起看看」「拍一张就知道啦」等亲切短句。
- 避免专业术语堆砌（拉丁名等可次级展示或不进 MVP）。
- 失败态温和：「没看清哦，再拍一张试试～」

## 明确不要

- 默认紫渐变科技风、玻璃拟态堆叠、过多数值仪表盘。
- 结果页只给唯一答案、无多候选滑动。
- 详情页底部做分享/评论（MVP 只要语音播报控制条）。
