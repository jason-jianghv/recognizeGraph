## 踩坑速查

> 格式：`症状 → 原因 → 解法`（新坑请插到表格最上方）

| 日期 | 症状 | 原因 | 解法 |
|------|------|------|------|
| 2026-08-11 | 18:00 LaunchAgent 未提交工作记录；`launchctl` 显示 127；err：`can't open input file: ...识图...` 乱码 | launchd 的 `ProgramArguments` 含中文路径会被弄坏，找不到 `daily-sync.sh` | 入口改为纯 ASCII：`~/bin/shitu-daily-sync.sh` 再 `exec` 仓库脚本；plist 的 WorkingDirectory 也勿用中文路径；改完 `launchctl bootout/bootstrap` 重载 |
| 2026-08-11 | 真机 App `errno=65`，Safari 通、服务端无 App 请求 | Dart `http` 不触发/不等待 iOS「本地网络」授权，立刻失败 | Info.plist：`NSLocalNetworkUsageDescription` + `NSBonjourServices`；AppDelegate 用 `NWBrowser` + `URLSession.waitsForConnectivity` 原生探测；MethodChannel `com.shitu/local_network`；删 App 重装并点允许 |
| 2026-08-11 | 百度识别 `216201 image format error` | HEIC/非 JPG·PNG 等格式不被接受 | 服务端 Pillow 转 JPG；支持 HEIC |
| 2026-08-11 | 识别 500：缺 `socksio` | Clash SOCKS 代理 + httpx 未装 socks | `pip install httpx[socks]`；百度请求 `trust_env=False` 直连 |
| 2026-08-11 | `git push` 输入口令后一直卡住 | SSH 已认证但连接 `CLOSE_WAIT`，常与代理有关 | `Ctrl+C` 后关代理/直连再推；口令用钥匙串记住 |
| 2026-08-11 | `Need to specify how to reconcile divergent branches` | 新版 Git 要求明确 merge/rebase | `git pull origin main --no-rebase --allow-unrelated-histories` |
| 2026-08-11 | 推送被拒：remote contains work you do not have | 建库时已有 README，历史分叉 | 先 pull 合并再 push，勿轻易 force |
| 2026-08-11 | vim 合并说明退不出去 | `git pull` 打开了 vi | `Esc` → `:wq` → 回车；或由脚本 `git commit --no-edit` 收尾 |
| 2026-08-11 | HTTPS push 要账号密码 / 设备无法交互 | GitHub 不支持密码推送 | 改用 SSH + `ssh-add --apple-use-keychain` |
| 2026-08-11 | Talk to Figma 命令超时 | 插件未响应或频道失效 | 重开插件并换新 channel |

#### 踩坑与解决

- 见上方「踩坑速查」本日数条（推送分叉、vim 卡住、代理导致 push 挂起、Figma 超时等）
