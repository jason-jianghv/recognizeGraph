## 3. 字体与字号

### 3.1 字体

| 平台 | 优先 |
|------|------|
| iOS / Figma 示意 | `SF Pro`（与现稿一致） |
| Android | `Sans Serif` 系统圆体或 `Noto Sans SC` |
| 原则 | 中文优先清晰可读；不做过分花哨手写标题 |

### 3.2 字号阶梯（逻辑 px）

| Token | Size | Weight | 行高建议 | 用途 |
|-------|------|--------|----------|------|
| `type.display` | 28 | Bold / Semibold | 34 | 页标题：探索世界、空间 |
| `type.title` | 24 | Bold | 30 | 详情/结果主名称（如「葫芦」） |
| `type.title-sm` | 20 | Semibold | 26 | 空间昵称区、卡片标题 |
| `type.body` | 17–18 | Regular / Medium | 24–26 | 简介、常规知识正文 |
| `type.body-sm` | 15–16 | Medium | 20–22 | 引导短句、列表次要行 |
| `type.caption` | 12–13 | Regular | 16–18 | Tab 标签、弱标注 |
| `type.badge` | 14–16 | Semibold | 18–20 | Lv、小标签 |

**儿童可读底线**：详情正文不小于 16；一句话简介尽量一行内读完（约 12–20 字）。

## 6. 组件约定

### 6.1 底部导航

- 左：胶囊 Tab（探索 / 空间）；选中浅灰底 + 主色图标/标签。
- 右：独立圆形拍照按钮（白底或浅玻璃 + 相机图标），视觉权重大于 Tab。
- 任意主 Tab 页都保留此结构。

### 6.2 顶栏标题

- 居中主色大标题（`type.display` + `color.text.accent`）。
- 空间页右上设置齿轮；探索页右上辅助入口可选。

### 6.3 拍照页

- **上半取景区**：实时预览；中央圆润取景框 + 白字提示「把小伙伴放进框里再拍哦」；左返回、右闪光。
- **下半白底操作区**：分类 Segment（动物 / 植物 / 交通工具与建筑）；相册（描边）| 主色大快门 | 翻转（浅底）。
- 摄像画面止于白底操作区上方，不铺满全屏盖住控件。

### 6.3b 对准裁剪页（相册选图后 / 拍照确认）

- **上半深色预览**：图可平移/捏合；框外压暗；中央取景框与拍照页**同几何**；右侧竖向缩放拉杆（显示如 `0.7x` / `1.5x`）。
- **缩放范围**：下限为「整图可落入取景框」（可小于 1x 铺满预览），上限 4x；避免角落大主体只能放大导致撑出框。
- **预览底提示**：白字「拖动或缩小图片，把要认的小伙伴完整放进框里」。
- **下半白底操作区**：左「重选」（主色描边胶囊）| 中主色圆形 ✓ 确定裁切 | 右浅底圆形关闭（放弃回拍照页）。
- Figma：Frame「对准裁剪页」（与「拍照」同壳 402×874）。

### 6.4 识别结果页

- 上半：用户原图；左返回（关结果+拍照）、右再拍。
- 下半：横向滑动候选；名称 + 一句话简介随滑动联动。
- 卡片可点进详情。

### 6.5 详情页

- 顶图 + 返回；右上语音偏好入口。
- 内容：名称（右侧浅桃圆钮点读）→ 英文名（主色 SemiBold 18，有则示）→ 简介 → 百科胶囊 → 常规知识（成语/动画等有则示）。
- 底部：**听一听介绍**；点击后弹出控制条 = 播放/暂停 + 进度条。无分享、无评论。

### 6.6 语音播报条

- 贴底 `color.bg.surface`，顶圆角 `radius.sheet`，轻阴影。
- 左：播放/暂停（≥48）。
- 中：进度条（轨道浅桃/浅灰，已播主色）。
- MVP 进度可只展示；拖动定位为增强项。

## 7. 动效（轻量）

| 场景 | 建议 |
|------|------|
| Tab / 按钮 | 150–200ms 透明或缩放 |
| 结果卡片滑动 | 跟手 + 吸附居中 |
| 播报条出现 | 自底部短距滑入 |
| 识别加载 | 友好插画/点动画，忌冰冷转圈 alone |
