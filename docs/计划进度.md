## 变更约定（给人看的）

1. **新增计划**：说一声即可；助手写入「下一步」并分配 `P-xxx`，必要时补 `PRD.md` §4 / `screens.md`。
2. **开始做**：状态改 `进行中`；可在工作记录当日「待继续」挂 ID。
3. **做完**：移入「已经完成」；PRD 表格改为「已做」或删掉「下一步」措辞；`screens.md` 勾选；当日工作记录留一句索引。
4. **大计划可拆切片**：如 P-005 → P-005a（已完成）+ P-005（余量仍待做）。
